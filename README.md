# Final Project

## Project Name
Final Project - Emotion Detector

## Project Description
This project implements an Emotion Detector application using the IBM Watson NLP library/service and Flask. It analyzes text and identifies five emotions: anger, disgust, fear, joy, and sadness, along with the dominant emotion.

## Technologies Used
- Python
- IBM Watson NLP
- Flask
- Requests
- Pylint
- Unittest

## Features
- Emotion detection from text input
- Formatted emotion scores and dominant emotion
- Flask web application
- Blank-input error handling
- Unit testing
- Static code analysis
